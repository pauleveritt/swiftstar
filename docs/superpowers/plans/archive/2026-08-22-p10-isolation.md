# P10 — Isolation: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: subagent-driven-development (or executing-plans). `- [ ]` checkboxes.

**Goal:** Worktree-isolated dispatch: a `HandoffPacket` in, a candidate ref (commit) or a receipt (typed refusal) out. No merge; the caller's tree is untouched. Consumes P9's host-authoritative facts.

**Architecture:** Pure `HandoffPacket`/`FileBaseline`/`DispatchOutcome` types and a pure `WorktreeDispatch` verdict mapping in Kit; `WorktreeDispatcher` (worktree create/remove, baseline read, validation, commit) in AppKit; the app runs a dispatched attempt (host mode, shell off, revision-checked) and shows the outcome.

**Tech Stack:** Swift 6.3, SwiftPM, swift-testing + git CLI (worktree). No engine/wire change (reuses P9's `--host-tools`).

**Spec:** `docs/superpowers/specs/2026-08-22-p10-isolation-design.md`

## Global Constraints

- Fast tier: no model/network/subprocess; git worktree is integration-tier.
- Binding rule 2 (shown-fail), rule 6 (evidence floor: the candidate ref resolves as a commit; a changed file differs from its baseline), rule 3 (typed assertions).
- D2: the worker gets read/write/edit + list/search; no bash; every mutation revision-checked against `writableFiles`.
- D3: outcome is a candidate ref or a receipt naming the reason; nothing merges.

## File Structure

- Kit: `HandoffPacket.swift`, `WorktreeDispatch.swift`, `DispatchOutcome.swift`; tests `HandoffPacketTests`, `WorktreeDispatchTests`.
- AppKit: `WorktreeDispatcher.swift`; integration test `WorktreeDispatchIntegrationTests`.
- App: `AgentController` dispatched-attempt mode; `DispatchView` (minimal tab).
