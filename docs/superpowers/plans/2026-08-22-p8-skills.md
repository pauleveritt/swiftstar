# P8 — Skills: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (or executing-plans). Steps use `- [ ]` checkboxes.

**Goal:** Bootstrap the Superpowers skills into the agent: a deterministic index passed via `-sys`, prefilled into `sysprompt.kv` (the engine's existing rebuild-on-mismatch behavior), with the full skill tree staged into the workspace for on-demand `read`.

**Architecture:** A pure `SuperpowersBootstrap` renders the index prompt; `AgentCommand` passes it via `-sys`; `SkillStager` copies the skills tree into the workspace; the agent discloses skills by `read`ing them (already confined to the grant). No engine patch.

**Tech Stack:** Swift 6.3, SwiftPM, swift-testing. No C, no wire change.

**Spec:** `docs/superpowers/specs/2026-08-22-p8-skills-design.md`

## Global Constraints

- Fast tier (`just test`): no model/network/subprocess; fixture reads by `#filePath` allowed.
- Binding rule 2 (shown-fail), rule 3 (no source-text assertions — assert on typed values / deterministic index membership), rule 6 (evidence floor: the bootstrap names every skill; the staged tree contains them).
- D5: never fabricate a dispatch call; disclosure is `read` only.
- The fake agent's strict-argv validation now includes `-sys <text>` — the integration tests must generate the same deterministic bootstrap.
- No engine patch; no `Package.swift` target changes.

### Task 1: `SuperpowersBootstrap` (SwiftStarKit)

**Files:** create `Sources/SwiftStarKit/SuperpowersBootstrap.swift`; test `Tests/SwiftStarKitTests/SuperpowersBootstrapTests.swift`.

**Interfaces:** `public struct SuperpowersBootstrap { public let indexPrompt: String; public let skillNames: [String]; public static func build(skillsDir: URL) -> SuperpowersBootstrap }`. `build` reads each `<skillsDir>/*/SKILL.md`, extracts its `name:` and `description:` front-matter lines (the first `name: ...` and `description: ...`), and renders:

```
You have Superpowers skills available. Load one before the work it covers.
To load a skill, read its SKILL.md inside the workspace (.swiftstar/skills/<name>/SKILL.md).

- brainstorming: <description>
- dispatching-parallel-agents: <description>
... (sorted by name)
```

Deterministic (sorted). If `skillsDir` is missing or has no skills, `skillNames` is empty and the prompt says "No skills available in this workspace." (degrade, never fabricate).

- [ ] **Step 1:** write the failing tests (deterministic build; skillNames contains the 14 names from a fixture skills dir; missing-dir degrade; index lines match `<name>:`).

- [ ] **Step 3:** implement. Read `name:`/`description:` from each SKILL.md via line scan (SKILL.md front-matter is `---\nname: X\ndescription: Y\n---`); fall back to the dir name when absent.
