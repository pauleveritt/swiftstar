# Kimi K3 deep review of Phase 11 (2026-08-23)

> **Superseded as a live finding** by [`2026-08-25-local-model-agency.md`](../2026-08-25-local-model-agency.md). Retained as the evidence record for Kimi K3's seven accepted bug fixes (stdin TOCTOU, parser discriminator, worker-id overflow) and the verified-not-a-bug dispositions.

**Status:** external adversarial review, captured as written. Reviewer: OpenRouter
`moonshotai/kimi-k3`. The accepted findings were fixed in order of severity; the
full response follows.

## Synthesis — accepted and fixed

- **Worker-id overflow** (Swift) — `PoolState` now holds a bounded free-list of
  worker-session ids (1…workerCapacity); the C side drops a prompt to a worker
  the pool does not host instead of clamping it to the orchestrator.
- **stdin TOCTOU** (C) — the main loop now `pthread_mutex_trylock`s `stdin_mu`
  after `poll()` returns, before reading.
- **Receipt misreported as "refused"** (Swift) — `DispatchReceipt.injectionPrompt`
  and `RollingDigestReducer.record` now distinguish a candidate (ref may be
  pending) from a refusal.
- **Parser ignored the `t` discriminator** (C) — `agent_parse_pool_prompt` now
  requires `t == "prompt"`, drops non-prompt JSON, and is gated on `num_workers
  > 1` so the N==1 wire treats every line as bare (pre-P11 behavior).
- **Rolling digest never fed** (Swift) — `consumeWire` now folds wire events and
  host verdicts into the digest.
- **Receipts cleared before the send** (Swift) — send-then-clear.
- **Interrupt routed to the wrong worker** (C) — now targets `generating_worker`.

## Deferred / verified-not-a-bug

- **Per-worker prompt queue + line-by-line parsing** (Kimi's Bug H) — latent: the
  app sends prompts turn-separated, so the 200 ms debounce aggregation does not
  bite the current flow; noted for the pipelined case.
- **Worker error kills the session** (Bug AS) — verified: budget exhaustion ends
  the turn normally (`stop_reason`) and reaches a `budgetExceeded` receipt via
  `WorktreeDispatch.verdict`; only genuine errors (Metal failure) hit the fatal
  `AGENT_WORKER_ERROR` path, which is acceptable.
- **Candidate ref still nil** — the pooled worker turns do not yet run in a
  per-worker worktree, so the commit SHA is not produced; the receipt no longer
  misreports it as a refusal ("candidate (ref pending)"), but the worktree
  integration is a follow-up.
- **Perturbation miscalibration** (Bug AI) — the `taskTextBloat*` arms multiply
  by 7 chars/repetition, so they over-bloat; irrelevant to the canonical arm but
  must be fixed before the sensitivity envelope pass.
